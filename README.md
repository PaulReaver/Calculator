# Calculator
A sleek calculator that performs all fundamental arithmetic functions. This was created as part of The Odin Project curriculum.

## Motivation
This project was made to:
- Develop my skills in receiving user input and translating it into correct numerical formats.
- Practice executing arithmetic operations on user data and promptly displaying the resulting calculations.

## Quick Start
Publicly available at the following link: https://paulreaver.github.io/Calculator/

## Usage
Users can perform basic arithmetic calculations by selecting numbers and operators. They can also clear the screen with *C* or use *Backspace* to correct mistakes.
